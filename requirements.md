# Asteroids Arcade Game Requirements

## Goal
Build a playable browser game inspired by the classic Asteroids arcade game.

## Gameplay
- Control a spaceship in outer space.
- Rotate the spaceship left and right.
- Move forward using thrust.
- Shoot asteroids using projectiles.
- Make large asteroids split into smaller asteroids when hit.
- Allow objects to wrap around screen edges.
- Increase the score when asteroids are destroyed.

## Controls
- Left Arrow: Rotate left.
- Right Arrow: Rotate right.
- Up Arrow: Move forward.
- Spacebar: Shoot.
- P: Pause or resume.

## Game Features
- Display the player's score and remaining lives.
- Include a start screen.
- Include a game-over screen.
- Allow the player to restart the game.
- End the game when the player runs out of lives.

## Technical Requirements
- Use HTML, CSS, and JavaScript.
- Run in a modern web browser.
- Support keyboard controls.
- Keep the code organized into separate files.
- Make the game playable on different screen sizes.

## Acceptance Criteria
- The spaceship moves and rotates correctly.
- Shooting can destroy asteroids.
- Destroying asteroids increases the score.
- Collisions affect the player's lives.
- Pause and restart work correctly.
- The game-over screen appears when all lives are lost.

## Development Order
1. Create the game screen.
2. Add spaceship movement.
3. Add asteroids and collision detection.
4. Add shooting and scoring.
5. Add lives and game states.
6. Test and publish the game.
